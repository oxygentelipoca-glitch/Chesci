# ChemFinder 参赛材料交接清单

项目为 ChemFinder 化学合成路线智能分析系统。团队编号 44590，所属院校为兰州交通大学。以下要求据团队提供的比赛材料整理。

| 官网提交项 | 要求 | 当前文件及待办 |
|---|---|---|
| 代码仓库（必交） | GitHub 或 Gitee，公开或授权评审。保留真实 Git 历史、清晰代码和有效注释。README 包含介绍、架构、安装运行与团队信息，附环境模板和依赖清单 | [README](../../README.md) 包含安装和团队信息。[比赛版 v0.2.0](https://github.com/oxygentelipoca-glitch/Chesci/releases/tag/v0.2.0) 提供固定提交、技术报告和复测说明 |
| 技术文档（必交） | PDF，最多 30 页。覆盖概述、需求、架构、AI 方案、核心功能、测试部署和总结展望，说明选型、集成、优化及两类创新 | [技术报告 PDF](技术报告.pdf)，共 6 页。[可编辑源稿](技术报告.md) |
| 演示视频（必交） | 时长 5–8 分钟，普通话讲解，MP4，至少 1080p。包含项目介绍、核心演示和 AI 技术亮点 | 已备 [录制稿](演示视频录制稿.md)。需要实际录屏、配音、导出成片 |
| 在线演示（可选加分） | 公网可访问，在评审期间保持可用。如需登录，提供评审专用测试账号 | 仅在部署并验证成功后填写公网地址和评审账号 |

## 提交前核实

- [ ] 对照报名记录核对队名、编号、姓名及 README 中的成员分工。
- [x] 公开仓库包含代码、参赛文档、依赖锁和环境模板。固定提交见比赛版本页。
- [x] 从公开仓库匿名克隆，在独立环境复测苯甲醛到肉桂酸、80 °C 筛选、论文来源和草案下载。
- [ ] 打开技术 PDF，确认学校、团队、链接、页数与提交版本一致。若修改源稿，重新导出并核对 PDF。
- [ ] 播放整段成片，核对时长、普通话音轨、分辨率、文字可读性和结尾。检查录屏中的凭据与个人信息。
- [ ] 通过大赛官网一次性提交仓库地址、视频和 PDF，保存回执。团队提供的国赛说明列作品提交截止日为 **2026 年 12 月 27 日**。省赛请按对应赛段通知核实。提交后如需修改，应联系组委会。
